01

一副底盘，两个杰作One Chassis, Two Masterpieces

一辆赛车和一件艺术品能共用一副底盘吗？Type 57 早就回答过。

1937 与 1939，Type 57 底盘两次赢得勒芒——车名 Type 57G「Tank」。同一副底盘，还诞生了被称作史上最美汽车的 Type 57SC Atlantic。

Destrier 与 Bolide 延续了这条传统：一副底盘，两种完全不同的表达。前挡风上方的铭牌由手工激光蚀刻，同时刻着 57G Tank 与 Atlantic——把这段渊源永远留在车上。

它是 Programme Solitaire 的第三件作品，继 Brouillard 与 F.K.P. Hommage 之后。前两件都从故事与历史中生长；Destrier 反过来，不靠故事，靠直觉与情感直接成形。

02

一米的宣言One Meter Tall

如果布加迪史上最强的工程，不装任何翼片、通风口和空力件——还剩什么？

答案是比例。

去掉全部气动附件之后，车身只剩干净的体量——全车只有一米高，比任何一辆布加迪都低。驾驶舱低伏在两片前翼子板之间，静止时也像一匹蓄势待发的战马。

Destrier 得名于中世纪骑士最优秀的战马：不是最重的，不是最快的，而是最可靠的。

03

呼吸的 C 线The Breathing C-line

C 线原本是一道不间断的亮条——在 Destrier 上，它开始呼吸。

布加迪的 C 线，传统上是一道环绕车身两侧的不间断亮条。Destrier 让它「呼吸」了。

在前轮拱前稍作停顿，露出裸车身，再继续它的路径，与更宽的马蹄形格栅交汇。车尾的融合翼呼应 Chiron Profilée，安静地收拢整个轮廓。

04

Sapphire CelesteThe Colour

蓝色不是随便选的——那台著名的「Pope」Atlantic，出厂时就是蓝色。

只为这一台车调的多层漆。

「Sapphire Celeste」随光线流转，让车身的体量显露出全部深度。漆层里的钻石闪光，在光线扫过时亮起来。抛光铝饰条衬着这层蓝。

历史在颜色里回响。

Type 57SC Atlantic 底盘 57591——绰号「Pope」的那台——出厂时就是蓝色，后来才被现任车主改喷黑色。Destrier 的蓝，是对那段渊源安静的致敬。

外露碳纤维只有两处：前分流器和后扩散器，色调专门配过这层蓝。

05

裁缝的工坊A Tailor's Atelier

座舱完全离开 Bolide 的竞技场——三种材质，定义了整个车厢。

每一种材质，都像裁缝选布。

「Ambre Voyageur」的皮革与翻毛皮，一种经得起时间的暖棕色；加上一种 3D 针织面料——从高定时装和运动服工艺里长出来的无缝三维表面。细铜线织入其中，绕成一道 halo 光环线，环绕整个座舱。锤纹铝在门把手、出风口、方向盘毂、迎宾踏板四处再现。

06

藏在车身下的 W16The W16 Beneath

一个几乎顺带一提的细节：与 Bolide 完全相同的动力总成。

和历史上那些优雅竞赛冠军一样，Destrier 的故事是比例与工艺，不是性能数字。

车身之下，是 Bolide 完整的 W16 动力总成——1,600 PS，四涡轮 8.0 升，布加迪这台发动机最成熟的形态。它是全车唯一原封不动的部分——因为不需要改。

2026 年 8 月 16 日，Pebble Beach Concours d'Elegance——它第一次见人。
